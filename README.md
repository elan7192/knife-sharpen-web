# 研刃 · 磨刀（three.js 原型）

和風低多邊形場景中的磨刀小遊戲。純靜態檔案（`index.html` + `main.js`），three.js 0.170 透過 CDN import map 載入，無需建置，支援 iPhone Safari（觸控）與桌面瀏覽器（滑鼠）。不載入任何外部模型、貼圖或 HDRI 檔案。

## 執行

ES module 需經由 HTTP 載入（不能直接以 `file://` 開啟）：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000/
```

手機測試：電腦與手機連同一個網路，開啟 `http://<電腦 IP>:8000/`。

## 操作方式

| 動作 | 觸控（iPhone Safari） | 滑鼠 / 鍵盤 |
| --- | --- | --- |
| 磨刀（來回推拉） | 單指在畫面任意處左右拖曳；往右推＝刀尖那段上石、往左＝刃根那段 | 按住左鍵左右拖曳 |
| 調整刀刃角度 | 拖曳時手指上下移動（往上＝角度變大）、第二指上下滑動、或右側角度滑桿（52 px 寬，可與磨刀手指同時操作） | 拖曳時上下移動、滑鼠滾輪、↑ / ↓ 方向鍵、右側滑桿 |
| 壓力 | 由按住時間與推拉速度決定：推太慢＝太輕，推太快＝太重 | 同左 |
| 試刀 | 點「試刀」按鈕（高度 ≥ 48 px） | 同左 |

觸控細節：畫布與控制項皆 `touch-action: none` 並 `preventDefault`，不會捲動頁面、不會雙指縮放或雙擊放大（viewport `user-scalable=no`）；HUD 與按鈕避開瀏海與 Home 條（`env(safe-area-inset-*)`）；旋轉螢幕自動重新取景。

### 規則（不計時、沒有失敗懲罰）

- **角度容許帶 15°–20°**：在帶內角度數字與燈號為綠色（帶外 3° 內為黃、再外為紅），進入帶內有「叮」一聲提示。帶外仍會慢慢進步，只是很慢。
- **壓力曲線**：綠區 30%–80% 效率最高；太輕＝進度慢；太重＝起毛邊（火花變多、磨聲變粗、提示「太用力會起毛邊」），進度變慢，但不會讓刀變鈍。
- **刃口覆蓋**：刃口分成 10 段（HUD「刃口亮線」格子，左＝刀尖、右＝刃根，與畫面上的刀同向）。正在石上的那段有紅框；磨過的段會在刀上亮起一條**刃口亮線**，第一筆推拉就看得到變化。每段到 25 / 50 / 75 / 100% 時響一聲**刃鳴**（WebAudio 合成的金屬鐘聲，段數越高音越高）並閃光；整條刃口都升一級時再加一段和弦與提示「全刃 第 N 段」。
- **鋒利度**＝10 段的平均，所以要左右推到兩端，讓整條刃口都亮起來。
- 刀為 21 cm 牛刀（gyuto）：PBR 金屬（metalness 1），越鋒利刀身越光亮（roughness 0.38 → 0.12），反射來自程式產生的環境貼圖（`RoomEnvironment` + `PMREMGenerator`）。

### 素材工房（第 7 輪主軸：把各種東西磨成刀，再用測試儀驗證）

標題畫面「開始・素材工房」→ 選素材 → 開場自動「磨前」測一次（通常是「切不斷」）→ 用 7 顆砥石逐級磨：
**#120 荒 → #220 粗 → #1000 中 → #2000 中 → #6000 細 → #8000 細 → 終局 #30000 鏡面**（每顆有鋒利度上限，粗石快、細石慢；#30000 才磨得出鏡面刀身）。
每顆磨到上限後按「測試」：**鋒利度測試儀**把刀夾住、壓向紅色測試線，指針爬升到線斷的瞬間（紅色峰值針留住讀數），顯示切斷力（克，越低越利）與等級
**鈍（≥600 g）／可用（300–599）／利（150–299）／剃刀（45–149）／傳說（<45）**，並在折線圖加一點（越利畫得越高）。測過才解鎖下一顆砥石。

- **鐵鏽菜刀**（主線金屬刀）：刀身鏽斑依刃段溶解剝落（粗石刷得快、細石慢），磨的時候泥水是鏽色；鏽沒除完前磨得很慢、讀數也偏重。目標：寶特瓶。
- **素材刀**（依序解鎖，完成上一把的目標試刀就解鎖下一把）：紙板（目標寶特瓶）→ 義大利麵（繩）→ 巧克力（寶特瓶）→ 果凍（繩，會抖）→ 冰（巨石）→ 石頭（鐵）。各有鈍度上限、磨速、程式繪製的外觀、磨屑顏色與一句原創旁白。
- 進度（解鎖素材、各素材最佳克數、完成紀錄）存在 localStorage `knife.lab.v1`。

### 試刀

依序挑戰：**番茄（15%）→ 紙（28%）→ 繩（42%）→ 寶特瓶（55%）→ 鐵（72%）→ 巨石（86%）→ 冰山（95%）**。進入試刀時畫面轉為「試刀高潮」色板（壓黑背景、冷色邊光、寬銀幕黑邊）；成功時慢動作下刀 → 刀光一閃＋**頓幀**（上限 120 ms）＋由大到小衰減的鏡頭震動 → 目標分成兩半（全部是載入時預先切好的兩半，不即時切割）。**寶特瓶**是第一個大高潮：刀幾乎水平橫掃，上半截順著切面滑落，慢動作多停 0.9 秒、鏡頭拉近，水從切口灑出（粒子在慢動作中懸在空中）＋水聲。未達標則刀被彈開。

## 效能與自動測試

- **自動畫質**（`perf.js`）：四級 低／中／高／極（像素比 1／1.25／1.5／2、陰影圖 512／1024／1024／2048、粒子 45%／70%／100%／100%、浮塵、HUD 毛玻璃）。手機從「高」開始（＝之前的固定設定）、桌面從「極」開始；每 2 秒判斷一次：中位數 < 50 fps 或最差 1% < 28 fps 就降一級（降過的等級本次不再嘗試），穩定 60 fps 6 秒就試著升一級；試刀演出中不調整；記住這台裝置上次的等級（localStorage `knife.quality`）。
- 靜態場景在載入後依材質一次合併（`batchStatic`），刀的鋼製零件合併成一個網格，空的粒子池不繪製，竹林不投影（量測在所有鏡頭都看不到它的影子）：每幀繪製呼叫 66 → 44、三角形 3.7 萬 → 2.95 萬，畫面不變。
- 開場先編譯所有著色器（含隱藏的試刀目標、切面、粒子），第一次試刀不會因編譯而卡頓。
- 只有太陽投影，行灯點光源不投影；粒子為固定池；主迴圈不配置新物件；HUD 只在數值改變時寫 DOM；分頁隱藏時暫停繪製與音訊。
- 測試掛鉤：`window.__game`（getter：`sharpness`、`angle`、`pressure`、`phase`＝`sharpen`/`test`/`result`，另有 `segments`、`stage`、`band`）；`window.__fps`（數字＝最近 60 幀平均，`.report()`＝`{ median, p1low, worstMs, frames }`，`.reset()` 重新開始量測）；`window.__perf()`（繪製呼叫、三角形、記憶體、畫質狀態）；`window.__quality`（`.state()`、`.set(i)`）。
- 自動測試：`node tests/stability.iphone13.mjs`（Playwright 無頭 iPhone 13；three.js 首次以 curl 快取到 `tests/.cache/`；截圖與分享圖輸出到 `tests/artifacts/`）。
- 效能量測：`node tests/perf/measure.mjs <輸出資料夾> --label before`（無頭 iPhone 13，統計每幀繪製呼叫／三角形／JS 毫秒並截圖）；`node tests/perf/governor.mjs`（畫質調整邏輯單元測試）。無頭 Chromium 用軟體繪圖，fps 不代表實機，見 `NOTES_perf.md`。
